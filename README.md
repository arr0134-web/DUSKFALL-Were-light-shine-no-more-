# DUSKFALL-Were-light-shine-no-more-
En este juego eres un explorador que en su larga travesía por lo desconocido se termina
topando con un reino antes glorioso ahora sumido en una oscuridad total. El “wanderer” como
se le conocerá en el juego, se aventurará por las antes concurridas calles del reino ahora
consumidas por una oscuridad que parece tener mente propia y sus habitantes consumidos y
torcidos a voluntad de esta.
Este juego será un estilo metroidvania 2.5D, contando con plataformeo incremental,
enemigos variados, diferentes zonas y laberintos y un sinfín de tesoros y misterios por
descubrir.
Este juego está inspirado en leyendas de este mismo género como “Hollow Knight”,
“Blasphemous” y “MIO (Memories in orbit)” pero con un estilo único y habilidades variadas
necesarias para llegar a diferentes secciones de este amplio reino.
Este juego contará con varios finales, todo dependiendo de las acciones que tome el jugador,
dirigido a un público joven y hardcore.
El juego se moldeará en Unity y será accesible a todo público para que nadie pueda
perderse el probar este juego
